Explanation
Data segment
Four strings ending in $, which tells DOS where printing stops. 13,10 is carriage return and line feed (new line).
Setting up DS
MOV AX,@DATA then MOV DS,AX. A segment register cannot take a constant directly, so the address goes through AX.
Greeting
AH=09h, INT 21h prints the string whose address is in DX. LEA DX,HI loads that address. It runs once, before the loop.
Loop (AGAIN)
Loads RED, YELLOW, GREEN in turn and calls SHOW for each. After green it checks the keyboard.
SHOW
Prints the string, then BIOS INT 15h, AH=86h waits CX:DX microseconds. 002DC6C0h = 3,000,000 us = 3 seconds.
Key check
INT 16h, AH=01h looks at the keyboard buffer without waiting. ZF=1 means no key, so JZ AGAIN repeats. A key press falls through to AH=4Ch, which exits to DOS.

The order is red, yellow, green (a real light is red, green, yellow). The key is checked once per cycle, so after a key press the current cycle finishes first, up to 9 seconds.

InstructionEffect
MOV AH,09h / INT 21hDOS: print string at DS:DX until $
MOV AH,86h / INT 15hBIOS: delay CX:DX microseconds
MOV AH,01h / INT 16hBIOS: check keyboard, ZF=1 if empty
MOV AH,4Ch / INT 21hDOS: terminate program
CALL / RETJump to a procedure and return
